Installing UE4SS

Set up the loader, then check the log before adding a mod.

What you need

  • The Windows version of Ballistic.exe.
  • A UE4SS release compatible with your game build.
  • A text editor, such as Visual Studio Code.

The local demo tests used UE4SS 3.0.1 Beta #0, commit 5e627997. This records a tested setup; it is not a recommendation to overwrite a working installation with a different release.

Downloads: UE4SS releases · Experimental builds.

Find the game folder

In Steam, open the game’s settings and choose Manage → Browse local files. From there, open:

Ballistic/Binaries/Win64/

You should see Ballistic-Win64-Shipping.exe. The smaller Ballistic.exe in the game’s top-level folder is a launcher. Install the loader beside the shipping executable.

Install the loader

  1. Close the game.
  2. Extract the chosen UE4SS package beside the shipping executable, preserving the package’s folder layout.
  3. Merge folders carefully if you already have other mods installed.
  4. Launch the game once, then close it and inspect the log.

The setup used for these guides has the following layout. Other loader packages can use a different working directory; follow the installation instructions for your release.

Win64/
├── Ballistic-Win64-Shipping.exe
├── dwmapi.dll
└── ue4ss/
    ├── UE4SS.dll
    ├── UE4SS-settings.ini
    ├── UE4SS.log
    └── Mods/

Check the log

Open ue4ss/UE4SS.log. Look for the loader version and startup messages. The file should have a fresh timestamp from your last launch.

If it is missing or unchanged, check the extraction location and that the files match your loader release. If the game crashes before mods load, resolve the loader setup before adding scripts.
