Shots & ballistics

A fired shot, a projectile impact and a valid target hit are separate events.

The shot pipeline

EventWhat it tells you
A_WeaponBase_C:ProcessBulletFiredWeapon firing event with cartridge, barrel and created bullet information.
C_BulletBase:RegisterHitA bullet reported impact information.
TargetBase_C:HitTarget hit path with projectile attribution in the inspected signature.
TargetBase_C:OnHitTarget reports validity, energy, velocity and bonus-related flags.

A projectile can strike non-target geometry. A target callback can be invalid. A shot counter and a scoring system should not increment from the same undifferentiated “hit” event.

Observe firing

Once the Blueprint function is loaded, a read-only hook can establish when it runs:

local path = "/Game/BlueprintLogic/Weapons/A_WeaponBase.A_WeaponBase_C:ProcessBulletFired"

-- Register once, after StaticFindObject(path) is valid.
RegisterHook(path, function(context)
    local gun = context:get()
    if gun and gun:IsValid() then
        print("[MyMod] Fired: " .. gun:GetFullName() .. "\n")
    end
end)

Observed shot arguments

After the context, the inspected firing signature has Cartridge, bullet and gas recoil forces, recoil location/direction, Barrel, powder amount, exit pressure, powder type and a Bullet array. Read the exact signature and unwrap parameters according to their type before using them.

Do not assume one event always produces exactly one bullet actor. Keep a shot ID and map each resulting projectile to it.

Impacts, energy and units

The target’s OnHit signature contains HitEnergy and HitVelocity, but a field name alone does not establish the units or all conversions used by the game. Record the raw values and compare controlled shots before labelling them in an overlay.

Don’t replace the game’s trajectory with a camera ray and call it the actual bullet path. A straight line can be useful as a cosmetic tracer, but it does not reproduce drop, penetration or ricochets.

What is not documented here

This guide maps events, not the complete internal ballistics model. Cartridge construction, powder curves, drag coefficients, penetration materials and every ammunition unlock rule still need dedicated research.

For score handling, continue to Hits & scoring.

What was checked

Firing and impact hooks resolved in local range checks; native target hit callbacks were also exercised. No full trajectory or ammunition-physics replacement has been validated. The examples describe the local Windows demo setup. See Checking game updates before using them on another build.
