7 November 2026

Added

  • The first nine guides: introduction, UE4SS installation, a first Lua mod, hooks, objects, debugging, game paths, custom content and tools.
  • Sixteen more guides covering timers and cleanup, data tables, weapon assemblies, attachments and rails, weapon stats, shot events, targets, scoring, workshop UI, ranges, saves, ownership, multiplayer architecture, packaging, update checks and coverage.
  • A grouped index of all guides and a coverage page explaining the limits of the current documentation.
  • Full-text search, keyboard shortcuts, navigation filtering, section links and code-copy buttons.
  • Dark mode by default, a saved theme choice, mobile navigation and print styles.
  • A contributor guide, pull request template and a manual GitHub Pages workflow.
  • This changelog, with a place to record future additions and fixes.

Changed

  • Organised the site into separate HTML guides with shared CSS and JavaScript.
  • Moved page titles, order and sidebar groups into one shared navigation file.
  • Grouped the expanded sidebar by topic and opened the current section automatically.
  • Added checks for page listings, local links and section anchors before building the site.
  • Rewrote the README as short setup and editing instructions, with badges for guide count and estimated coverage.

Fixed

  • Long reference tables now scroll inside the article on phones instead of squeezing the text into narrow columns.
  • The README coverage badge now opens the coverage page.
  • Search can be closed with Escape, and the header search label stays on one line.
  • Corrected Windows path handling in the local preview and build tools.
