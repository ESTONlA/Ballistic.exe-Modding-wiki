Game paths & classes

Useful locations and names observed in the Windows demo.

Build-specific reference

These paths were checked locally on Steam demo build 26083142. They are a starting point for discovery, not a promise that another release has the same objects.

File locations

LocationPurpose

Workshop functions

The attachment point widget uses this class path:

/Game/UI/HUD/Workshop/BunkerHUDItems/Attach_POI.Attach_POI_C
FunctionObserved role
GetCompatibleMountsRecursiveMount-compatibility lookup.
OnGetUserMenuContentAttachment popup creation.
SetupAttachmentFitting or removing an attachment.

The workshop HUD is /Game/UI/HUD/Workshop/HUD_Workshop.HUD_Workshop_C. Its attachment editor is named WeaponEditMOde; preserve that spelling when looking it up.

Weapon classes

/Game/BlueprintLogic/Weapons/A_WeaponBase.A_WeaponBase_C
/Script/Ballistic.C_WeaponBase

The Blueprint weapon base exposes UpdateCharacteristicsFromParts. In the inspected build it has nine boolean inputs. Check the full signature in your own dump before calling it.
