Barrel heat & cooling

Measure the game’s temperature fields and cooling transitions without assuming the field names reveal the full heat model.

Start with a cold baseline

The names below are recorded in the local object snapshot dated 10 October 2026. That snapshot does not identify its game build. Resolve the same names in your current build before using them; the investigation steps below are not a report that every operation was tested.

The native barrel exposes temperature-related fields. Some names contain Ambiant and arbitrary coefficients; preserve those spellings when looking them up. They describe the schema, not proof of a particular unit conversion or physical formula. Use one barrel, one cartridge and one assembly for the first comparison.

Take bounded samples

Sample at a modest fixed interval and store ordinary numbers. A temperature graph does not need a UObject retained for each point. Reacquire the current barrel after changing assemblies, and clear the graph when the world or gun changes. A missing barrel is a missing observation, not zero kelvin.

-- Context: barrel is a valid current C_BarrelBase-derived actor.
local sample = {
    current = barrel.CurrentKelvinTemperature,
    ambient = barrel.AmbiantKelvinTemperature,
    rate = barrel.ArbitraryCoolingRate,
}
-- Copy numeric values, not the actor, into your chart buffer.

Run a heating and cooling experiment

  1. Wait without shooting and record whether the current value settles toward the ambient field.
  2. Fire a fixed, small number of shots with identical ammunition. Record shot times and subsequent samples.
  3. Stop firing and record the cooling curve over the same interval.
  4. Repeat once at a lower frame rate to reveal sample-timing mistakes.
  5. Change one cooling-related attachment using the normal workshop flow and repeat the same experiment.

Avoid comparing two guns with different barrels, loads and cooling modifiers and attributing the result to only one field. Record the complete configuration with the plot.

Interpret the result carefully

If the displayed graph jumps when you reopen a menu, first check that you did not switch to a newly constructed barrel actor. A visual heat effect, an accuracy drift and a numeric temperature can update at different points. Treat them as separate signals until their relationship is measured. Converting kelvin to Celsius is appropriate only after you confirm the field actually contains a temperature in kelvin for this build.

Useful mod outcomes

  • A read-only heat gauge with the raw value and clear unit assumptions.
  • A cooling-comparison tool that records identical shot schedules.
  • A diagnostic that distinguishes a replaced barrel from genuine cooling.
  • A bounded history buffer that resets after travel and does not write to saves.
