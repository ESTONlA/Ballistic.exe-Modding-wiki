Lua basics for modding

Understand the language before adding Unreal objects to the mix.

Before you start

Finish Your first mod so you have a script whose log message you can find. Use a disposable test mod for the snippets here. Copy one example at a time, restart, and compare its output with the explanation before combining examples.

The examples use Lua, as loaded by UE4SS. Luau is a related language with different features; don’t paste Roblox services, Luau type annotations or Roblox instance APIs into a UE4SS script and expect them to exist.

1. Values and local variables

local enabled = true
local sampleLimit = 12
local label = "My mod"
local currentWeapon = nil

print(label .. ": " .. tostring(sampleLimit) .. "\n")

local limits a variable to its surrounding scope. true and false are booleans; 12 is a number; quoted text is a string; nil means no value. Two dots join strings. Use tostring when a value might be a number, boolean or nil.

Lua treats only false and nil as false in a condition. The number 0 and an empty string are both truthy. If a setting must be a boolean, validate its type instead of assuming that zero disables it.

2. Conditions and early returns

local function describe(value)
    if value == nil then return "No value" end
    if type(value) ~= "number" then return "Not a number" end
    if value < 0 then return "Negative number" end
    return "Zero or positive number"
end

print(describe(nil) .. "\n")
print(describe(-2) .. "\n")

Expected output is No value, then Negative number. == compares values; = assigns a value; ~= means not equal. Each if needs then and end. Early returns make object checks easier to read because the main operation does not sit inside several nested conditions.

3. Functions and callbacks

A function is a value you can call or hand to another function. A callback is a function handed to something that runs it later. Do not call the callback while registering it.

local function onPressed()
    print("[MyMod] Key callback ran.\n")
end

RegisterKeyBind(Key.F9, onPressed)
-- Do not write RegisterKeyBind(Key.F9, onPressed()).

The final comment shows a common mistake: the parentheses execute onPressed immediately, then pass its result to RegisterKeyBind. Without the parentheses, the function itself is registered. Choose a key not already used by another mod.

4. Tables and loops

local names = {"barrel", "rail", "grip"}
for i, name in ipairs(names) do
    print(i .. ": " .. name .. "\n")
end

local settings = {Enabled = true, MaxParts = 12}
print(tostring(settings.MaxParts) .. "\n")

Ordinary Lua list indices conventionally start at one. ipairs walks a dense sequence until the first nil. A keyed table is useful for settings or named state. settings.MaxParts is shorthand for settings["MaxParts"].

These rules describe Lua tables. A UE4SS wrapper for an Unreal array, set or map is a different object with its own supported operations. Don’t use a table example as proof that an engine container supports the same iterator. See Arrays and containers.

5. Dot versus colon

local counter = {value = 0}
function counter:add(amount)
    self.value = self.value + amount
end

counter:add(3)
-- Equivalent ordinary Lua call: counter.add(counter, 3)
print(counter.value .. "\n")

A colon call supplies the receiver as the first argument. Use the form expected by the API you’re calling. object:IsValid() and module.create() are not interchangeable conventions. In engine bindings, an incorrectly called function can fail before your intended operation happens.

6. Errors and type checks

A syntax error prevents the chunk from loading. A runtime error occurs while executing a loaded chunk. If a variable is nil, ask why it never received a value rather than adding a default that hides the missing object.

pcall returns a success boolean followed by the result or error. It catches Lua errors, not every native access violation. assert is useful for rejecting an invalid configuration immediately; it is less helpful as a replacement for waiting for an expected menu to load.

Practice before engine work

  1. Change the sample limit and predict the output.
  2. Pass a string to describe and confirm the type branch.
  3. Make a list of three labels and print each once.
  4. Put the counter in its own module, following Organising a mod.
  5. Only then introduce a real weapon or widget reference.

If a plain Lua example fails, solve that first. Adding Unreal state makes a language mistake harder to isolate.
