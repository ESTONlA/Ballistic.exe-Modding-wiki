Weapon assemblies

A visible gun is an assembly of actors and components, not necessarily one mesh.

Find the equipped weapon

In a range, the local pawn exposes EquippedWeapon. The workshop uses its own displayed weapon reference, so don’t expect the range pawn to identify the gun on the workbench.

local H = require("UEHelpers")

RegisterKeyBind(Key.F9, function()
    ExecuteInGameThread(function()
        local pc = H.GetPlayerController()
        if not pc or not pc:IsValid() then return end
        local pawn = pc:K2_GetPawn()
        if not pawn or not pawn:IsValid() then return end
        local gun = pawn.EquippedWeapon
        if not gun or not gun:IsValid() then return end

        print("[MyMod] Equipped: " .. gun:GetFullName() .. "\n")
    end)
end

Parts and components

Observed weapon classes include C_WeaponBase, C_WeaponPart and the Blueprint A_WeaponBase_C. Parts expose a ParentWeapon reference. ChildActorComponents can own attached part actors, which can have their own descendants.

Enumerate the assembly before changing it. A core barrel, a fitted rail and a nested foregrip can live at different depths. Reading just the root actor’s mesh misses much of the weapon.

local children = {}
gun:GetAllChildActors(children, true)
for i = 1, math.min(#children, 128) do
    local child = children[i]
    if child and child:IsValid() then
        print("[MyMod] Part: " .. child:GetFullName() .. "\n")
    end
end

Templates are different from live actors

CurrentWeaponTemplate records a selected assembly. A spawned weapon is the live actor built from it. Changing the visible actor alone does not establish that the saved template changed, and changing a template does not automatically refresh every existing actor.

The observed template has separate weapon-class, main-part, attachment and grip data. The generated field names have suffixes; inspect the current struct rather than copying offsets.

Visible doesn’t mean usable

A mesh proxy can show another player’s gun without implementing its firing mechanism. A usable gun also needs the correct actor class, parts, ammunition, ownership and input path.

Test local use separately from remote appearance. Likewise, hiding a source gun and drawing a replacement mesh does not make a new inventory weapon.

Test an assembly

  1. Record the selected template and visible part tree.
  2. Change one part and confirm only the expected branch changes.
  3. Leave the workbench and test handling and firing.
  4. Travel to a range and back.
  5. Restart and check the saved assembly separately.

What was checked

EquippedWeapon lookup and assembled mesh capture were used in local range fixtures. Arbitrary replacement weapons, imported models and every possible assembly are not verified. The examples describe the local Windows demo setup. See Checking game updates before using them on another build.
