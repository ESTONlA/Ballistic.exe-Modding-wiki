Arrays, sets & maps

Read Unreal arrays, sets and maps without confusing them with ordinary Lua tables.

1. Identify the container first

An ordinary Lua table and a reflected Unreal container can look similar in a short snippet while supporting different operations. Read the field type from the dump before choosing an iterator. The local PurchasedParts field is a set, UnlockedRanges is an array, and SavedWeaponTemplates is a map.

ContainerQuestion it answers
Array / TArrayWhat is at this index, in this ordered collection?
Set / TSetDoes this typed value belong to the collection?
Map / TMapWhich value is associated with this typed key?
Plain Lua tableWhat state did my script construct itself?

2. Don’t mix index bases

The tested UE4SS array wrappers in these guides used numeric indices starting at one. UMG panel methods such as GetChildAt used zero-based indices. C++ examples also commonly use zero-based array indexing. Copy the convention belonging to the actual API rather than assuming a language-wide rule.

-- A tested reflected-array pattern:
for i = 1, #points do
    local point = points[i]
    -- Validate point before using it.
end

-- A UMG panel method pattern:
for i = 0, panel:GetChildrenCount() - 1 do
    local widget = panel:GetChildAt(i)
    -- Validate widget before using it.
end

3. Bound discovery and report truncation

The original attachment/range investigation found that ipairs on a particular Unreal wrapper could continue past the reported length. Numeric iteration using the reported count avoided that failure. This is a recorded binding-specific result, not a claim that ipairs is broken on Lua tables.

A diagnostic can print the first twelve items and say the rest were omitted. A clear-all feature cannot silently process twelve and report that everything was removed. Decide whether an excessive count causes a stop, a visible partial result or a bounded multi-step job.

4. Reacquire after mutation

Removing a child part can rebuild the menu’s array of POI widgets. Iterating the old array after the native action may use stale references. Perform one action, let the refresh happen, then acquire the new collection before continuing.

Copying every element into a Lua list does not necessarily solve lifetime: those elements may still point at native widgets that were just destroyed. Copy plain identifiers for your plan and resolve live objects at the moment of the next action.

5. Match set and map key types

A set of soft class references requires the representation expected by its binding. A string that prints like the class path and a loaded UClass are not automatically equivalent keys. Start with a known contained value and a known absent value; inspect result and stability independently.

Map enumeration can also be loader-specific. Don’t publish a generic pairs call over a reflected map just because it works on your own Lua dictionary. Use the supported API for your loader and keep a small native fixture for sensitive membership operations.
