Working with hooks

A hook runs your code when the game calls an Unreal function.

Find a function

Use the UE4SS object viewer or an object dump to locate the exact reflected function path. Class names and function names are case-sensitive. A Blueprint function often has a path like this:

/Game/UI/HUD/Workshop/BunkerHUDItems/Attach_POI.Attach_POI_C:GetCompatibleMountsRecursive

This path was observed in the demo’s attachment UI. It may not be loaded until workshop assets are present.

Wait for the function

Don’t assume a Blueprint is available when main.lua first runs. Check for it on the game thread, and register your hook once.

local path = "/Game/UI/HUD/Workshop/BunkerHUDItems/Attach_POI.Attach_POI_C:GetCompatibleMountsRecursive"
local installed = false

LoopAsync(2000, function()
    if installed then return end

    ExecuteInGameThread(function()
        if installed then return end
        local fn = StaticFindObject(path)
        if not fn or not fn:IsValid() then return end

        RegisterHook(path, function(context)
            local object = context:get()
            if not object or not object:IsValid() then return end
            print("[MyFirstMod] Workshop lookup called.\n")
        end)

        installed = true
        print("[MyFirstMod] Hook installed.\n")
    end)
end

Read parameters carefully

Hook arguments can be UE4SS parameter wrappers. Use the access pattern documented for the parameter’s type, and inspect the signature before reading or changing it. Callback phase and return-parameter behaviour can differ between native and Blueprint functions.

The sample above only reads the context and logs a call. It does not alter mount compatibility or attachments.

Avoid common mistakes

  • Don’t install the same hook on every timer tick.
  • Don’t call the hooked function from its own callback unless you have a deliberate recursion guard.
  • Don’t assume a path from an older game build is still correct.
  • Don’t use a Lua error handler as protection against native memory crashes.

Check the UE4SS API documentation for your loader version before writing to parameters or relying on pre/post callbacks.
