Game hook reference

Look up exact reflected paths with a statement of what was observed and what was tested.

Read the evidence before the call

This is a curated reference, not a recovered SDK. Each path below was checked against the local object dump when the catalog was created. “Recorded local integration path” means the related callback/action appears in the recorded local checks; the notes preserve the narrower test scope. It does not promise every parameter or assembly works on your build.

A dump-observed getter is a discovery point until a runtime check establishes the intended call. Verify your game/loader version and the loaded owning class before installing a hook. The current RegisterHook semantics are explained in Working with hooks.

How this reference is maintained

The table of entries comes from observed-hooks.json. The build validates identifiers/evidence labels and regenerates the catalog from that file. It does not inspect your running game or certify compatibility with a newly installed update.

For a new finding, include the actual path, types/context, test method and what remains untested. Do not promote a symbol from dump-only to exercised because a similarly named function worked elsewhere. Follow Reading object dumps and the testing workflow.
