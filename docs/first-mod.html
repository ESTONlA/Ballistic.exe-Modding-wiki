Your first mod

Create a mod folder, write one Lua file, and check that it runs.

Create the folder

Inside your loader’s Mods folder, create MyFirstMod. Add a Scripts folder and an empty file named enabled.txt.

ue4ss/Mods/
└── MyFirstMod/
    ├── enabled.txt
    └── Scripts/
        └── main.lua

Enable file extensions in Windows Explorer so the script isn’t accidentally saved as main.lua.txt.

Write the script

Open main.lua in a text editor and add:

local function log(message)
    print("[MyFirstMod] " .. message .. "\n")
end

log("Loaded successfully.")

Use a distinct prefix in every log message. It makes your output easy to find when several mods are enabled.

Run the mod

  1. Save the file.
  2. Fully close and restart the game.
  3. Open ue4ss/UE4SS.log.
  4. Search for [MyFirstMod] Loaded successfully.

If the message appears, your script is loading. If it doesn’t, check the folder names and the log’s Lua errors.

Add a keybind

This example logs a message when you press F9. Choose a key that does not conflict with another mod.

RegisterKeyBind(Key.F9, function()
    print("[MyFirstMod] F9 pressed.\n")
end
Keep engine work on the game thread

A log message is a small first test. If your keybind changes Unreal objects, schedule that work with ExecuteInGameThread. See Finding game objects.

Disable or share the mod

With the game closed, remove the mod’s enabled.txt to disable it. For a small Lua-only release, package your mod folder, scripts and enable marker with clear installation instructions. Don’t bundle the game, saves, logs or your entire UE4SS installation.
