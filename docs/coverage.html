How to read coverage

The README percentage is a rough estimate of game-specific documentation, not a measured fraction of all source code, assets or possible mods. Adding setup pages does not establish that more gameplay systems are fully understood.

The useful measure is whether a guide gives you a reliable entry point, an example and a clear limit. The table below makes those limits visible without treating every topic as complete.

Evidence levels

  • Found in a dump: the name or field existed in the inspected build.
  • Native fixture: an operation ran against actual engine objects in an isolated test.
  • Local gameplay check: the feature was exercised in the game’s menu or range.
  • Real peer check: separate PCs/accounts performed the scenario together.

These levels are different, not interchangeable. A native fixture does not automatically prove a player’s saved assembly or an internet session works.

Known open questions

The exact owned-only attachment rule remains unresolved. A reported rail-removal stat penalty was not reproduced by the recorded synthetic fixture. A visible custom range card did not establish a new map, and runtime-scene lighting experiments did not produce a finished custom range.

The ballistics, ownership and multiplayer guides explain the relevant boundaries in more detail.
