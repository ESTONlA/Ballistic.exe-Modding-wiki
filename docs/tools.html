UE4SS

The loader runs Lua mods and exposes Unreal objects and functions. Match API guidance to your installed version; the development documentation may describe APIs newer than your local loader.

  • Releases and downloads
  • Installation guide
  • Development documentation
  • Lua API overview

Game inspection

Start with the UE4SS object viewer and object dump to inspect what the current game session has loaded. Use an archive browser when you need to look for cooked content that isn’t loaded yet.

  • FModel — Unreal archive browser.
  • FModel getting started — configuration and usage.

Tool support depends on the game’s engine and archive format. Finding an asset in an archive does not guarantee it can be loaded in every game mode.

Unreal modding

UE_Modding by Dmgvol collects techniques and guides for Unreal games. Use it to research asset-based mods alongside the Lua approach described here.
