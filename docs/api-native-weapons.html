Source: a local loaded-object dump file dated 10 October 2026. Its Steam build was not recorded. These are observed declarations, not an official SDK or a report that all entries were called successfully. Unloaded assets and engine/plugin classes are outside this catalog.

Class fields are directly declared fields, not the complete inherited state. Function field lists can include inputs, outputs, returns and Blueprint locals because the dump does not record enough flags to distinguish them. Do not turn their order into positional Lua arguments. Open the recorded class in the current runtime before using a new path.
